# Banking Loan Approval Analytics

An end-to-end data analytics solution analyzing banking loan applications, approval trends, and applicant risk metrics using **Excel**, **SQL**, and **Power BI**.

## Project Overview
This project transforms raw loan application records into an interactive executive dashboard to help evaluate approval rates, loan disbursement trends, and key risk indicators across customer segments.

## Tools & Technologies
* **Microsoft Excel:** Data cleaning, standardization, and initial exploratory checks (`loan_approval_dataset Cleaned.csv`)
* **SQL:** Business queries, aggregations, and segmentation analysis (`A1_Banking_Loan_Analysis_Queries.sql`)
* **Power BI & DAX:** Data modeling, custom DAX measures, KPI cards, and interactive multi-page executive dashboard (`Banking_Loan_Executive_Dashboard.pbix`)

## Repository Files
* `loan_approval_dataset Cleaned.csv` – Cleaned and formatted loan approval dataset
* `A1_Banking_Loan_Analysis_Queries.sql` – SQL queries used for exploratory and business analysis
* `Banking_Loan_Executive_Dashboard.pbix` – Interactive Power BI dashboard file
